# Crop Recommendation System

A Machine Learning-based crop recommendation system that predicts the most suitable crop based on soil nutrients and environmental conditions. This project uses agricultural and environmental data to assist in intelligent crop selection using machine learning techniques.


---

##  Project Overview

The system analyzes important environmental and soil parameters such as:

 Nitrogen, Phosphorus, Potassium, Temperature, Humidity, pH, Rainfall

The project demonstrates:
 * Data preprocessing
 * Exploratory Data Analysis (EDA)
 * Feature analysis
 * Machine learning classification
 * Model evaluation

---


## Technologies Used

 * Python
 * Pandas
 * NumPy
 * Matplotlib
 * Seaborn
 * Scikit-learn

---


## Dataset Features

Feature	Description:

 * N: Nitrogen content in soil
 * P: Phosphorus content in soil
 * K :Potassium content in soil
 * Temp: Environmental temperature
 * Humidity: 	Air humidity
 * pH: Soil pH value
 * Rainfall: Rainfall amount

Target variable:
 * Recommended Crop : 22 Crops.

---

## Machine Learning Workflow

The project follows a complete ML workflow:

* 1. Data Loading
* 2. Data Cleaning
* 3. Exploratory Data Analysis
* 4. Feature Selection
* 5. Train-Test Splitting
* 6. Model Training
* 7. Model Evaluation
* 8. Crop Prediction

Model Used :  Random Forest

## Evaluation

The project evaluates model performance using:
 * Accuracy score: 99.318%
 * Classification metrics
 * Prediction analysis
 * Feature Importance: Rainfall contributes most and pH least to predict recommended crop.
